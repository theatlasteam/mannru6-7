# Маннру Charts — графики для плагинов

Встроенная зависимость `ctx.charts` — движок SVG-графиков без внешних библиотек.
Доступен во всех GUI-плагинах (`ctx.charts`) и таб-плагинах
(`this.$ctx.charts` или `this.$charts`). Каждый график возвращает объект
`{ svg() }` — SVG-разметку для вставки через `v-html`.

Цвета графиков автоматически следуют теме приложения (primary-цвет + CSS-переменные),
кроме свечей — у них собственные цвета (зелёный/красный, настраиваются).

```js
// GUI-виджет: вернуть SVG прямо в render(ctx)
render(ctx) {
  return '<h3>Курс за неделю</h3>' + ctx.charts.line({ data: [62, 64, 63, 67, 66, 70, 72] }).svg()
}

// Таб-плагин: через this.$charts
mounted() {
  this.svg = this.$charts.candle({ data: this.candles }).svg()
}
// <div v-html="svg"></div>
```

---

## `line({ data, labels?, width?, height?, fill? })` — линия / область

```js
ctx.charts.line({
  data: [1, 4, 3, 8, 5],       // массив чисел (null — пропуск точки)
  labels: ['Пн', 'Вс'],        // подписи по краям
  width: 320, height: 180,     // размеры SVG
  fill: true                   // заливка области (по умолчанию true)
}).svg()
```

## `bar({ data, labels?, width?, height? })` — столбцы

```js
ctx.charts.bar({
  data: [12, 7, 15, 9, 20],
  labels: ['Янв', 'Фев', 'Мар', 'Апр', 'Май']
}).svg()
```

## `candle({ data, labels?, width?, height?, up?, down? })` — японские свечи

```js
ctx.charts.candle({
  data: [
    [10, 12, 9, 11],     // [open, high, low, close]
    [11, 14, 10, 13],
    [13, 13.5, 8, 9],
  ],
  labels: ['10:00', '11:00', '12:00'],
  up: '#22c55e',          // цвет растущей свечи
  down: '#ef4444'         // цвет падающей
}).svg()
```

Элементы можно передавать и объектами: `{ o, h, l, c }`.

## `pie({ data, labels?, width?, height?, colors?, donut? })` — секторная диаграмма

```js
ctx.charts.pie({
  data: [40, 30, 20, 10],
  labels: ['Курс', 'Награды', 'Донаты', 'Прочее'],
  donut: true            // кольцо с итогом в центре (по умолчанию false)
}).svg()
```

При передаче `labels` справа рисуется легенда. Палитра по умолчанию
(можно переопределить через `colors`):
`#7c4dff, #26c6da, #66bb6a, #ffa726, #ef5350, #ab47bc, #ec407a, #26a69a`.

---

## Заметки

- Все параметры опциональны, кроме `data`. Числа автоматически нормализуются.
- Если данных недостаточно, возвращается SVG с подписью «нет данных».
- Графики — чистые функции: одинаковые входные данные дают одинаковую разметку.


---

## Живой пример

```js
// Нажмите «Запустить» — свечи отрисуются прямо здесь
return ctx.charts.candle({
  data: [[10,12,9,11],[11,14,10,13],[13,13.5,8,9],[9,11,8,10],[10,13,9,12],[12,12.5,9.5,10]],
  labels: ['10:00','11:00','12:00','13:00','14:00','15:00']
}).svg()
```
