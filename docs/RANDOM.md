# Маннру Random — случайности для плагинов

Встроенная зависимость `ctx.random` — генераторы случайностей и игровые помощники.
Чистый модуль: работает в GUI-окнах, таб-плагинах и серверных хуках.
Требует `utils` (подтягивается автоматически — достаточно `dependencies: ['random']`).

---

## Базовая генерация

| Функция | Описание | Пример |
| --- | --- | --- |
| `next()` | случайное число 0..1 | `random.next()` |
| `int(min, max)` | целое в диапазоне (включительно) | `random.int(1, 6)` → кубик |
| `float(min, max)` | дробное в диапазоне | `random.float(0, 1)` |
| `chance(p)` | да/нет с вероятностью p (0..1) | `random.chance(0.5)` |
| `coin()` | орёл/решка | `random.coin()` |
| `dice(sides?, count?)` | сумма кубиков | `random.dice(6, 2)` → 2d6 |

## Работа с массивами

| Функция | Описание | Пример |
| --- | --- | --- |
| `pick(arr)` | случайный элемент | `random.pick(['камень', 'ножницы', 'бумага'])` |
| `weighted(items, weights)` | элемент с весами | `random.weighted(['редкий', 'обычный'], [0.1, 0.9])` |
| `shuffle(arr)` | перемешать (копия) | `random.shuffle(cards)` |

## Детерминированный генератор `prng(seed)`

Одинаковый сид — одинаковая последовательность. Идеально для честных игр
и воспроизводимых розыгрышей.

```js
const rng = ctx.random.prng(42)
rng.next()               // число 0..1
rng.int(1, 100)          // целое
rng.float(0, 10)         // дробное
rng.chance(0.3)          // да/нет
rng.pick(['a', 'b'])     // элемент
rng.shuffle([1, 2, 3])   // перемешать
```

## Игровые помощники

| Функция | Описание | Пример |
| --- | --- | --- |
| `deck()` | перемешанная колода 52 карты `{ rank: '2'..'A', suit: '♠♥♦♣', value: 2..14 }` | `const cards = random.deck()` |
| `slot(reels)` | слоты: по одному символу с каждого барабана | `random.slot([['🍒','7','🍋'], ['🍒','7','🍋']])` |

```js
render(ctx) {
  const cards = ctx.random.deck()
  const hand = cards.slice(0, 2)
  return '<b>Ваши карты:</b> ' + hand.map(c => c.rank + c.suit).join(' ')
}
```

## Живой пример

```js
const rng = ctx.random.prng(42) // детерминированный сид
return {
  кубик_2d6: ctx.random.dice(6, 2),
  монета: ctx.random.coin() ? 'орёл' : 'решка',
  три_карты: ctx.random.deck().slice(0, 3).map(c => c.rank + c.suit),
  сид_42_повторяется: [rng.int(1, 100), rng.int(1, 100)]
}
```
